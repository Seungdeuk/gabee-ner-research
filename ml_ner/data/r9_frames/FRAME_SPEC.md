# R9 학습 데이터 문형 틀(frame) 작성 명세

가족 메신저(카카오톡 같은 가족 단톡·1:1 대화)에서 개인정보(사람 이름 등)를 가리는 한국어 NER 모델의 **학습용** 문장 틀을 만든다. 틀은 슬롯이 든 한국어 문장이며, 별도 생성기가 슬롯에 이름·별명·호칭·단어를 채워 학습 문장을 만든다. 모든 문장은 합성이어야 하고 실제 가족 대화·실제 개인정보를 쓰지 않는다.

**작업 제한(중요)**: 이 명세 파일과 지정된 출력 파일 외의 어떤 파일·폴더도 열거나 읽지 마라(저장소의 다른 데이터, 평가셋, `sealed` 폴더 포함). 출력은 지정된 경로에 JSON 파일 하나로 쓴다.

## 출력 형식

JSON 배열, 항목마다 아래 필드(UTF-8, 들여쓰기 자유):

```json
{"id": "msgp-001", "scenario": "일정·약속", "text": "{N1:sub} 내일 학원 끝나고 곧장 온대", "tags": ["person"]}
```

- `id`: 파일 접두어 + 3자리 번호(고유). `scenario`: 시나리오 이름. `text`: 슬롯이 든 문장. `tags`: 파일별 지침의 태그(없으면 빈 배열).
- 같은 파일 안에서 `text` 가 중복되면 안 된다. 어휘만 바꾼 틀(예: 단어 하나만 다른 같은 구조)을 반복하지 말고, **문장 구조·말투·목적·길이가 서로 달라야** 한다.

## 슬롯(대소문자 정확히)

| 슬롯 | 채워지는 것 | 라벨 |
|---|---|---|
| `{N1:k}` `{N2:k}` `{N3:k}` | 사람 이름(2~4글자, 성 있거나 없음) | PERSON |
| `{AL1:k}` `{AL2:k}` | 사람을 가리키는 별명·애칭(2~3글자) | PERSON_ALIAS |
| `{NK1:k}` | 이름 + 가족 호칭(예: 이름 엄마, 이름 할머니). **이름 부분만** 라벨 | PERSON(이름만) |
| `{K1:k}` `{K2:k}` | 가족 호칭 단독(엄마, 아빠, 할머니, 이모, 삼촌 등) | 라벨 없음 |
| `{W1:k}` | 일반 명사(자연물·사물·계절 등) | 라벨 없음 |
| `{NW1:k}` | 일반 명사와 같은 글자의 **사람 이름**(사람 문맥에서만 쓸 것) | PERSON |
| `{WN1:k}` | 위와 같은 글자의 **일반 명사**(명사 문맥에서만 쓸 것) | 라벨 없음 |
| `{L1}` `{L2}` | 지명·랜드마크(조사는 틀에 직접 적는다) | LOCATION |
| `{O1}` `{O2}` | 병원·학교·학원·회사 등 기관 이름(조사는 틀에 직접 적는다) | ORGANIZATION |
| `{AD1}` | 주소(도로명+번호 등) | ADDRESS |
| `{PH1}` `{EM1}` `{AC1}` | 전화번호, 이메일, 계좌번호 | 규칙 몫(NER 라벨 없음) |

`:k` 는 슬롯 바로 뒤에 붙는 조사 종류로, 생성기가 받침에 맞춰 조사를 붙인다(이름·단어 끝 글자에 따라 이/가, 은/는 등):

- `sub`(이/가), `top`(은/는), `obj`(을/를), `com`(랑·하고·와 계열), `dat`(한테·에게 계열), `voc`(아/야, 호격), `pos`(의)
- `bare`: 조사 없음. **슬롯 바로 뒤가 공백·쉼표·문장부호·문장 끝**이어야 한다.
- `lit`: 조사를 생성기가 붙이지 않고, 틀에 직접 쓴 글자가 바로 이어진다(예: `{N1:lit}라는 아이`, `{N1:lit}한테서`).
- `{L1}`, `{O1}`, `{AD1}`, `{PH1}` 등은 `:k` 없이 쓰고 뒤 글자는 틀에 직접 적는다(예: `{L1}에서 만나자`).

같은 슬롯 이름(`{N1:..}`)을 한 문장에 두 번 쓰지 마라. 두 사람이 나오면 `N1`, `N2` 를 쓴다.

## 정책(r9-1.1)

- 사람 이름은 이름 부분만 PERSON. 가족 호칭(엄마·아빠·언니·할머니 등)은 **라벨 없음**이다. 이름 뒤 호칭은 `{NK1:k}` 로 쓰고, 호칭만 있는 문장은 `{K1:k}` 로 쓰며 보호 대상 이름이 없으면 음성이다.
- PERSON_ALIAS 는 사람을 지칭하는 실제 별명·애칭 자체만이다. `이름+호칭`을 별명 슬롯으로 쓰지 마라.
- 조사·호칭·따옴표는 슬롯 밖이다.
- **1글자 이름이 연상되는 문장 금지**(예: 이름이 한 글자인 경우). 이름 슬롯은 2글자 이상이다. 문장에 1글자 이름을 직접 쓰지 마라.
- 틀 안에 구체적인 사람 이름·유명인 이름·실제 상호를 쓰지 마라(이름은 슬롯으로만).

## 품질

- 말투: 가족 메신저의 자연스러운 한국어. 반말 중심에 존댓말도 일부, 문어체·안내문은 해당 파일 지침을 따른다. 오타·ㅋㅋ·ㅠㅠ 같은 표현은 생성기가 따로 입히므로 틀에는 넣지 않아도 된다(넣어도 된다).
- 길이 10~110자. 질문·명령·평서·감탄, 화자 관점, 연결어, 문장 시작 위치(문두·문중·문말)를 다양하게. 이름 슬롯이 항상 문장 첫머리에 오지 않게 한다.
- 시나리오는 가족 생활(일정·약속, 학교·학원, 안부·심부름, 정산·돈·구매, 사진·영상 공유, 병원·건강, 이동·방문, 잡담)에서 고루.
- 욕설, 성적·폭력적 내용, 정치, 실제 개인을 비방하는 내용 금지.
