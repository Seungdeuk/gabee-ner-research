# v9 — 최종 잠금 독립 평가셋 (2026-11-16)

**이 평가셋은 한 번만 쓴다.** 결과를 보고 R3 모델/데이터를 추가로 조정하지 않는다(사용자 지시).
운영 모델 교체는 이 결과와 별개로, 별도 승인 사항이다.

## 무엇을 검증하는가

`NER_VALIDATION.md` 50절에서 목적격·여격·호격·비교서술 문형이 약하다는 걸 진단했고, 51절(우선순위 2·
2단계)에서 `ml/ner/data/build_r3_phrase_collision_data.py`로 이 문형들을 보강한 모델(R3)을 만들었다.
R3가 **학습에 쓴 8개 충돌 단어·holdout 4개를 넘어, 한 번도 보지 않은 새 충돌 단어에도** 일반화되는지가
이 v9의 질문이다.

## 독립성 근거

- 단어 10개(진달래·민들레·억새·솔잎·눈송이·빗방울·들꽃·메아리·솔바람·꽃잎)는 R3 학습용 8개·holdout
  4개와 같은 방식(전체 이름 풀·48절 진단셋·v4~v8 평가셋 대조)으로 걸러낸 **같은 후보군의 나머지 10개**다
  — R3 데이터 어디에도, 과거 어떤 평가셋에도 없다(`build_v9_locked.py`의 `leak_check`가 자동 확인).
- 문장 틀은 R3 학습/holdout 틀과 문자 그대로 다르게 새로 썼다.

## 구성(100문장)

| 그룹 | 문장 수 | 내용 |
|---|---|---|
| A_new_phrase | 40 | 새 충돌단어 10개 × 신규 문형 4개(목적격·여격·호격·비교서술) |
| A_neg | 20 | 같은 10개 단어의 비PERSON(일반명사) 문장, 단어당 2개 |
| B_basic_phrase | 20 | 같은 10개 단어 × 기존에 이미 잘 통하던 기본 문형 2개(회귀 확인용) |
| D_background_neg | 20 | 충돌 단어와 무관한 일반 배경 문장(배경 오탐률) |

## 사용 규칙

1. 기존 모델·R3 후보(선정된 대표 시드)를 동일 조건에서 이 셋으로 딱 한 번 비교한다.
2. 결과가 나쁘더라도 평가셋이나 모델을 다시 손대지 않는다 — 있는 그대로 보고한다.
3. 다음 개선 작업은 이 v9조차 재사용하지 않고 새 v10을 만든다.
