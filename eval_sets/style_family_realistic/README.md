# 실제 가족 메신저 대화체 평가셋 (전부 합성)

사용자 요청으로 만든 추가 확인용 세트다. "실제 가족 대화"를 테스트해 달라는 요청이었지만, **실제 대화 데이터는 절대 쓰지 않는다**(프로젝트 규칙, `CLAUDE.md`) — 대신 기사체·공문·명단 같은 문체를 빼고, 가족 채팅방에 흔한 말투(호칭+이름을 섞어 부르기, 안부·일정·소소한 사건을 한 메시지에 담기, 이모티콘·줄임말)만 담은 **더 현실적인 합성** 평가셋을 만들었다. 2026-11-12 실행 결과: 222문장(메신저 200 + 비인명 22), 이름 span 260개, sha256 앞 12자 `5683e117e326`.

로드맵 1~5단계의 정식 테스트(v4 devset, v5 잠긴 최종 테스트)와는 별개다 — 공식 단계가 아니라 "실제 가족 대화에 더 가까운 문체에서도 같은 개선이 보이는지" 추가로 보기 위한 보조 확인이다. 학습 풀·baseline_v2·v3·v4·v5 전부와 이름·문장 틀이 안 겹치게 만들었다(겹치면 생성이 실패한다).

## 한계 (반드시 읽을 것)

- **이것도 합성 데이터다.** 실제 가족 대화를 흉내 낸 것일 뿐, 실제 대화의 다양성·문맥·오탈자 패턴을 다 담지 못한다. "실 서비스 투입 가능"의 근거로 이 결과만 쓰면 안 된다.
- 문장 틀 20개를 사람이 직접 썼다 — 실제 대화에 있을 수많는 표현을 대표하지 못한다.
