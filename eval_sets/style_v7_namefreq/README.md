# v7 평가셋 — 공공 이름 빈도 통계 기반 대규모 PERSON 평가 (전부 합성 문장)

사용자가 제공한 출생신고 이름 빈도 집계 2개(여아·남아, "이름,개수"만 있는 공개 통계)를 합쳐 중복 제거한 뒤,
건수 상위 300개("고빈도")·하위 300개("저빈도")를 뽑아 성씨 유무(2)·조사 유무(2)를 조합해 2,400개 PERSON
문장 + 78개 비인명 문장(총 2,478문장)을 만들었다. **blind_v6(440개)보다 훨씬 큰 표본**이고, blind_v6 와는
완전히 분리된 새 평가셋이다(겹치는 이름·문장 없음, blind_v6 는 전혀 읽지 않았다).

- 2026-11-16 생성. 생성: `build_v7_namefreq.py`. 평가: `../../../../scripts/eval_v7_namefreq.py`
  (서비스 경로 `ner.detect_with_ner`만 측정, NER 단독은 측정하지 않음).
- **데이터**: 이름 문자열과 건수만 있는 공개 집계 통계(실제 개인 식별정보 없음)에서 이름만 추출했고, **문장은
  전부 새로 지은 합성 문장**(가족 메신저체, blind_v6 와 다른 새 템플릿)이다. 실제 가족 대화는 전혀 쓰지 않았다
  (프로젝트 데이터 정책 준수).
- 변수: 빈도(고빈도 상위 300/저빈도 하위 300, 건수 동률 구간 포함) × 성씨(없음/흔한 성 10개 중 1개, 이름마다
  고정 배정) × 조사(없음/있음, 받침에 따라 자동으로 "이" 또는 "가").
- 비인명 78문장(자연물 명사 26개 × 템플릿 3개)은 blind_v6 와 다른 새 단어로 만들었다 — **의도적으로 "조사
  없이 문장 맨 앞에 선 2~3음절 명사"라는, 모델이 약한 패턴만 모아 놓은 스트레스 테스트**다. 그래서 이 평가셋의
  비인명 오탐률은 blind_v6(더 자연스러운 문장)의 오탐률과 **직접 비교하면 안 된다** — 서로 다른 난이도의
  평가다.
- 결과: `results_service_vs_r1s7.json`. 분석은 `docs/security/NER_VALIDATION.md` 42절.

## 한계

- 성씨는 이름마다 해시로 고정 배정했다(실제 성명 통계와의 결합 분포는 아니다).
- 모든 긍정 문장이 "이름이 문장 맨 앞 주어"라는 한 가지 통사 위치만 테스트한다(문장 중간·목적어 위치는
  blind_v6 의 다른 카테고리가 이미 다룬다).
- 비인명 26단어는 과거 세션에서 이미 오탐이 확인된 단어 일부(바다·노을·하늘 등)를 포함한 **의도적 스트레스
  셋**이라, 전체 FPR 수치를 "실제 서비스 환경의 오탐률"로 대표값처럼 인용하면 안 된다.
