# 우선순위 2 · 1단계 산출물 — 합성 데이터 초안(DRAFT, 미적용)

**상태: 초안일 뿐이다.** 이 폴더의 `synth_draft.jsonl`은 `ml/ner/data/synth.py`에 추가되지도,
어떤 학습에도 쓰이지 않았다. 사용자가 1단계("읽기 전용 진단 및 학습 데이터 설계")까지만 진행하기로
했고, 2단계(파인튜닝)는 별도 승인 후에만 진행한다. 모델 재학습·운영 코드 변경 없음.

## 진단 근거

`apps/api/scripts/analyze_candidate_gap_step1.py`로 `style_ambiguity_probe`(48절) 자연·계절/
일상·추상 26단어의 PERSON 문맥 3문장(템플릿 T1/T2/T3)을 다시 뜯어봤다
(`apps/api/app/shared/privacy/eval/style_ambiguity_probe/candidate_gap_step1.json`).

**템플릿별 "후보 없음"(원시 후보조차 안 생김) 집계**(26단어×3템플릿=78, 서비스/R1 평균):

| 템플릿 | 서비스 | R1 |
|---|---|---|
| T1 "~이/가 오늘 피아노 학원 다녀왔대" | 0/26 | 0/26 |
| T2 "어제 ~한테 전화했는데 안 받더라" | 4/26 | 5/26 |
| T3 "우리 반에서 ~가 제일 웃겨" | 4/26 | 1/26 |

**결론 1 — 어휘 공백만의 문제가 아니다.** 26단어 중 `ml/ner/data/synth.py`의 `GIVEN2`(실제 학습
이름 사전)에 있는 건 "이슬·지성·다정" 3개뿐인데도, 나머지 23개 미등록 단어 대부분이 T1·T3에서는
정확히 탐지된다 — 서브워드·분포적 유사성으로 일부 일반화가 되고 있다. 실패는 **특정 단어 × 특정
문형의 조합**에 몰려 있다.

**결론 2 — 두 모델 공통으로 템플릿에 취약한 단어 7개**: 가을·미소·사랑·새벽·수정·여름·이슬.
이 중 "이슬"은 학습 사전에 있는데도(즉 이름으로 쓰인 적을 모델이 알면서도) T1에서는 맞히고 T2/T3
일부에서는 놓친다 — 등재 여부와 무관하게 **문형 커버리지 자체가 비어 있다**는 뜻이다. 특히 T2(격식
없는 여격 "~한테")는 두 모델 다 가장 약한 문형이다.

**결론 3 — 비PERSON 문맥에서는 대부분 과탐지가 없다(원시 예측 기준 null이 다수)**, 단 이미 학습
사전에 있는 "이슬·노을·장미·지성" 등 일부는 **진짜 일반명사 문맥에서도 원시 점수 0.9대로 PERSON을
강하게 예측**한다(`candidate_gap_step1.json`의 `nonperson_raw_prediction_by_word`). 최종 경로에서는
억제되지만(48절 비PERSON 오탐률 집계상 낮음), 어휘 자체의 PERSON 사전확률이 맥락보다 강하게 작용하는
사례가 이미 존재한다는 신호다 — 데이터 보강 시 "이름으로도 흔한 단어"의 **비PERSON 예문도 균형 있게
늘려야** 이 역방향 문제가 커지지 않는다.

## 초안 설계 원칙

1. 실패가 몰린 7단어(가을·미소·사랑·새벽·수정·여름·이슬)에 집중한다.
2. 실패 문형(T2 여격 "~한테", T3 "~가 제일 ~")을 반드시 포함하되, 기존 `synth.py`의
   `TEMPLATES`/`AUG_TEMPLATES`에 이미 있는 다른 문형(소유격, 완료형 서술, 가족 메시지체 등)도 섞어서
   "이 단어=이름"이라는 신호를 여러 문형에서 주도록 한다.
3. **PERSON 문장마다 같은 단어의 비PERSON(원래 뜻) 문장을 짝지어** 넣는다 — 결론 3에서 본 역방향
   문제(일반명사 문맥 과탐지)를 키우지 않기 위해, "이름으로 쓰일 때와 아닐 때"를 대비시키는 균형
   데이터로 설계했다.
4. 문장은 전부 새로 썼다(기존 평가셋 문장 재사용 금지 — v6/v7/v8/진단셋과 중복 없음, `used_names_
   exclusion.json` 로직과 별개로 **문장 자체**가 새 것인지만 수동 확인함).
5. 성씨 결합형(예: "김여름")은 넣지 않았다 — 성씨 효과는 이미 48절에서 따로 확인됐고(28/30, 거의
   완전 방어), 이번 초안의 목적은 **성씨 없이도** 모델이 맥락만으로 구분하게 만드는 데이터이기 때문.

  쓰려면 `ml/ner/data/synth.py`의 `TEMPLATES` 구조에 맞게 훨씬 큰 규모로 확장해야 한다.
