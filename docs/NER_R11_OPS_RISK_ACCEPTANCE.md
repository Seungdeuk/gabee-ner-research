## 3. 수용 대상 잔여 위험
1. **D1P 노출률 40%** — 일반명사 형태 이름은 S0(43%)와 사실상 같게 계속 새어 나간다. 교체로 해결되지 않는다.
2. **A3N 오탐 5%→10%** — 유의하지 않으나(구간 −1.8~+12.9) 악화 방향.
3. **A3 노출 19%** 등 일부 유형 노출 잔존.
4. **합성 데이터·사람 검수 미실시** — 라벨 정확도·숨은 PERSON 누락·오류율 미측정, D1P 문맥 단서로 낙관 가능, 실사용 분포 차이.
5. **NER 미적용 경로가 존재한다는 사실** — 메인 AI 채팅, knowledge_ask, 문서 OCR/PII, 사진 판별(가명화 없음), 일정 제안·call_talk·관리자 챗봇(규칙 마스킹만), 메인 채팅→가족 채팅 에이전트 도구 구간은 `required` 에서도 NER 실패 때 호출된다. **이 경로들이 안전해졌다고 주장하지 않는다.** 보호 정책 변경은 별도 작업(후속 과제)으로 기록한다.
6. **최소 개선 폭 미달** — 사전 등록 요구(Recall +10 %p, 노출률 −8 %p, F1 +8 %p)에 못 미쳤다(+8.90, −6.84, +6.39). 개선은 실재하나 사전 등록 기준은 충족하지 못했다.
7. **Cloud Run 운영 장애·롤백 위험** — `required` 이므로 모델 로딩 실패 시 NER 연결 입구가 503 이 된다(가족채팅 AI·일정 에이전트 등 서비스 중단). 롤백은 이전 리비전·이미지가 남아 있을 때만 가능하며(삭제 금지), 롤백하면 R11 개선이 사라지고 S0 위험으로 돌아간다. 서비스에서 런타임 모드·지문을 직접 볼 수 없어 일회성 Job(같은 digest)과 후보 URL 스모크로 간접 확인한다.
8. 운영 환경 미검증 항목(S2b·S4)이 남아 있으면 수용 불가.
