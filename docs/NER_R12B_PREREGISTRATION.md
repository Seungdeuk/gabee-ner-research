# NER R12b 사전 등록 (PERSON 노출률 5% 이하, 문맥 일반화 개선, 마지막 고도화 시도)

버전 r12b-prereg-1.0. 작성 시점: R12b 학습·평가 **전**. 표시: 자동 검증 기반 연구용 · 사람 검수 미완료. 마감 2026-11-25(수) 17:00. 이번이 PERSON 고도화의 마지막 시도다. 이 문서의 수치·규칙은 결과를 본 뒤 바꾸지 않는다(바꾸면 태그를 새로 달고 이유를 기록한다).

## 0. 범위와 보호
- R11 모델·ONNX(`3831601b…`)·봉인 평가셋(`r11_stress_v1`, `EVALUATED.lock`)·`KEEP_S0`·운영 상태, R12 모델·산출물(`ner-runs/r12/…`)은 건드리지 않는다. R12b 는 별도 경로(`ner-runs/r12b/…`, 데이터 `ner-runs/data_r12b/`)에만 쓴다.
- 하지 않는 것: 이름 사전 운영 적용, 새 이름 Regex 추가, 서비스 코드 변경, 게이트를 결과에 맞춰 변경, 시드 사후 선택, 유료 외부 API 호출, Cloud Run 배포, 봉인셋 열람.
- 데이터 작성은 이 세션의 Claude Code 서브에이전트(모델: Sonnet·Opus·Haiku·Fable 5.x 순환)로 한다. 외부 유료 API 는 쓰지 않는다. 서브에이전트 호출 수는 배치 수(§3)와 같고 보고서에 기록한다.

## 1. R12 실패 원인 분석(데이터 진단 `ml/ner/analysis/r12b_data_diagnosis.py`, 학습 없이 파일만 읽음)
(가설이며 신경망 내부로 확정된 것은 아니다. 데이터에서 관측된 사실만 적는다.)
1. **조사·띄어쓰기 단서의 비대칭**(대조쌍 문장, 낱말 바로 뒤 첫 글자): `r12_extra` 명사 문장은 42.9%가 낱말 뒤 공백(조사 없음), 사람 문장은 15.7%뿐이다. `한테`(사람 125 : 명사 1), `아`·`야`(사람 98 : 0)는 사람 쪽에만, `이 `(0 : 88)는 명사 쪽에만 나온다. 한쪽 라벨에 90% 이상 쏠린 단서(8회 이상)가 64종이고 그 단서가 쌍 문장의 53.9%를 덮는다. `r12_dev`도 명사 60.5%가 낱말 뒤 공백, 사람은 16.1%.
2. **단서만으로 푸는 분류기**(낱말 자체는 가리고 앞뒤 문맥 n-gram 만 사용): `r12_extra`로 학습 → `r12_val` 95.4%, `r12_dev` 89.9%, **`r11_dev` 65.5%**(무작위 50%). `r11_B_extra`로 학습 → `r11_dev` 79.1%, `r12_dev` 67.5%. 작성 방식 단서가 분포 안에서는 거의 다 풀어 주고 다른 분포에서는 통하지 않는다.
3. 어휘 겹침은 원인이 아니다: 개발 쌍 단어·PERSON 값이 학습과 겹친 비율 0%(R11 학습 대비 PERSON 값 1% 이내). 개발 문장의 학습 최근접 유사도도 낮다(r12_dev 평균 0.235, r11_dev 0.181).
4. 결론: R12 데이터는 문맥이 아니라 **낱말 뒤 형태(공백·`한테`·`아/야`)와 문체 단서**로도 풀리는 구조였다. R12b 는 이 단서를 균형 잡아 제거하고(§3), 작성자·장르를 늘린다.

## 2. 학습 구성(하나로 고정)
- 모델·조건은 R12 와 같다: KoELECTRA-small, max_len 128, batch 32, lr 5e-5, 최대 8에폭, patience 2, warmup 0.1, weight decay 0.01, 시드 **7·13·21·42·99**, `--klue-ratio 0`.
- 학습 데이터 = R11 B군(`baseline_train`, `synth_train`, `klue_train:469`, `r9_Ffull_train`, `r11_B_extra`) + **신규 `r12b_extra`**. **`r12_extra`는 쓰지 않는다**(단서 비대칭 원인 가설을 검증하는 단일 비교: R12 = 같은 구성 + `r12_extra`).
- 체크포인트 선택: `--select-on r12b_val`(겹침 F1). 시드 5개 전부 학습·보고(실패 시드 포함). SWA·평균·추가 실험·하이퍼파라미터 탐색 없음.

## 3. 신규 데이터 `r12b_extra`/`r12b_val`/`r12b_dev` (문장별 직접 작성, 템플릿 치환 금지)
| 세트 | 목표 | 구성 |
|---|---:|---|
| `r12b_extra`(학습) | ≈2,280 | 대조쌍 1,200(300단어 × 사람 2 + 명사 2), 성 없는 2자·전체 3자 이름+조사·호격 280, 별명 100, 인접·나열·다인물 200, 경계 B1/BND 160, 가족 채팅 자연문 340(이름 유 120 / 이름 없음 음성 220) |
| `r12b_val` | ≈440 | 쌍 240(60단어 × 4), 나머지 R12 val 구성과 비슷한 혼합 200 |
| `r12b_dev` | ≈440 | `r12b_val` 과 같은 구성, 단어·이름·문장 별개 |
- **단서 균형 규칙(작성 브리프와 검증기 `check_r12b_marked.py` 가 강제)**: 낱말 뒤 형태를 ⓐ공백·쉼표·문장 끝 ⓑ이/가 ⓒ은/는 ⓓ을/를 ⓔ랑·하고·와·과 ⓕ한테·에게·께 ⓖ아·야 ⓗ그 밖으로 나눠, ① 사람·명사 각 역할 문장에서 한 묶음이 60%를 넘지 않는다, ② 쌍(`k1`)의 사람·명사 문장은 같은 묶음을 쓴다(쌍의 50% 이상), ③ 명사 문장의 10% 이상이 ⓕ·ⓖ 형태, 사람 문장의 20% 이상이 ⓐ 형태. 배치 단위로 검사한다.
- **다양성**: 배치마다 장르 프로필(단체 대화 여러 화자, 메모·일정, 질문-답, 공지문, 혼잣말, 사진·영상 공유 캡션 등)과 작성 모델이 다르다. 서로 다른 모델 4종이 같은 비율로 작성한다. 같은 틀(앞 3어절+종결) 4-gram 중복·문장 중복·세트 간 겹침을 제거한다.
- **누출 통제**: 개발·검증 단어·PERSON 값은 R11·R12 의 모든 데이터와 겹치지 않는 새 값만 쓴다. 학습 단어는 R11/R12 개발·검증 단어를 쓰지 않는다. 세트 간 단어·이름·문장·틀 겹침 0 을 assert.
- **데이터 품질 게이트(학습 전, 실패하면 학습하지 않고 데이터를 고친다. 개발 결과를 보지 않는다)**: 낱말을 가린 문맥 단서 분류기(진단 스크립트와 같은 코드)를 `r12b_extra` 쌍 문장으로 학습했을 때 (a) 5-겹 교차검증 정확도 ≤ 70%, (b) `r12b_dev`·`r12_dev`·`r11_dev` 정확도 ≤ 72%. 한쪽 라벨 90% 이상 단서 중 쌍 문장 덮는 비율 ≤ 25%.
- 합성 문장이며 사람 검수는 하지 않는다.

## 4. 개발 단계 게이트(독립 평가 **전**, R11 대비 같은 세트에서) — R12 와 동일, 완화 없음
세 세트 `r11_dev`, `r12_dev`, `r12b_dev` 모두에서 시드 후보가 아래를 만족해야 적격이다(기존 두 세트는 R12b 학습 데이터와 작성 방식이 다른 분포 밖 세트).
1. Exact Precision(공식) ≥ R11 − 2.0 %p
2. D1 일반명사 오탐률 ≤ R11 + 3.0 %p
3. 음성 FPR(`r11_dev` NEG 4집합 매크로, `r12_dev`·`r12b_dev` 는 FAM_NEG) ≤ R11 + 1.5 %p
4. PERSON 전체 노출률 < R11 (같은 세트)
5. KLUE val F1 ≥ R11 − 1.0 %p
6. ONNX 토큰 일치 ≥ 99.9%, 크기·p50 지연·RSS ≤ R11 × 1.30(p95·RSS 는 확정 시드만 측정)
- 시드 확정: 적격 시드 중 **세 세트 PERSON 전체 노출률 평균이 가장 낮은 시드**(동률이면 F1 높은 쪽). 적격 시드가 없으면 후보 없음(독립 평가 없음, 판정 UNVERIFIED 또는 미채택).
- 추가 보고(게이트 아님): 완전·부분 노출, Recall, F1, D1P Recall/노출, 쌍 문맥 정확도, R12(`r12_extra`) 시드와의 같은 세트 비교.

## 5. 독립 평가(새 평가셋, 한 번만)
- 평가셋: `r12b_stress_v1`(1,200: D1P 250·D1 250 쌍 포함, 지시서 고정 유형 수량)와 `r12b_representative_v1`(600). 제작 지시서 `NER_R12B_EVALSET_PRODUCER_INSTRUCTIONS.md`, 전달 패키지 `gabee-ner-evalset-r12b-handoff\`(별도 GPT 세션, 평가셋의 쌍 조사 균형 규칙 포함). 수령 후 변환·검증·겹침 측정·수량 맞춤·봉인.
- **후보가 확정되기 전에는 열지 않는다.** 확정 후 같은 세트에서 S0·R11·R12b(확정 시드)를 평가한다(쌍 클러스터 paired bootstrap 5,000회). R11 봉인셋 수치(10.23%)와 직접 비교해 개선 폭을 계산하지 않는다.
- 채택 권고 조건(모두 충족, 같은 세트의 R11 대비): (1) PERSON 전체 노출률 ≤ 5.0%(스트레스·대표 모두) (2) Precision ≥ R11 − 2.0 %p, F1 ≥ R11 − 0.5 %p (3) D1 오탐 ≤ R11 + 3.0 %p, 음성 FPR ≤ R11 + 2.0 %p(대표 세트 ≤ +1.5 %p) (4) 지연·크기·RSS ≤ R11 × 1.30.
- 결과 분류: 채택 권고 / 채택 보류(노출 개선, 2·3 위반) / 5% 미달(수치·원인 보고, 재학습 금지) / **UNVERIFIED**(독립 평가셋 미준비·미완료). 독립 평가 결과로 모델·시드·임계값·데이터를 다시 고르지 않는다. 임의 합격 처리·모델 교체 금지.
