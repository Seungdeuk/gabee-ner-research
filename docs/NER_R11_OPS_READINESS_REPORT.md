## 4. 가명화 적용 범위 — NER 교체만으로 보호되지 않는 경로
- **NER 이 적용되는 경로(교체 효과 있음):** 가족채팅 분석·답장·주제·미리보기, 일정 에이전트 채팅, @가비 방 맥락, 주간 뉴스 라벨, quiz, 가계 에이전트의 질문·history.
- **R11 효과 확인(동일 합성 시나리오):** S0 는 이름 조각 `박서`가 분석·답장·주제 본문에 남고 토큰 일치 8/10 → R11 은 조각 잔류 없음, 10/10.
- **required 이어도 NER 실패 시 Claude 를 호출하는 입구(NER 미연결):** `schedule_suggestions`(규칙 마스킹만), `assistant_chat`(메인 채팅), `knowledge_ask`. 또한 메인 채팅→가족 채팅 에이전트 경로는 NER 실패 시에도 200으로 진행(규칙 마스킹 결과 사용). `billing_agent` 는 503 차단. 이 경로들은 모델을 바꿔도 보호가 달라지지 않으며 **별도 정책 과제**다.
- **auto 모드:** NER 실패 시 규칙·등록 이름만으로 외부 전송(fail-open). 운영은 `required` 여야 한다.

## 5. 운영 위험(잔여, 숨기지 않음)
D1P(이름이 일반명사 형태) 노출률 R11 40.0%(S0 43.0%, 사실상 개선 없음), 회귀 유형 A3 노출 19%, A3N 오탐 5%→10%(구간 −1.8~+12.9, 유의하지 않음), R11-S 연구 게이트 미충족(적격 시드 1/5, Seed 21 은 사후 선택), 사람 검수 미실시, 합성 데이터·강한 문맥 단서에 의한 낙관 가능성, 실사용 분포와의 차이.

## 6. 배포 전 마지막 조치
1. 운영 담당자가 `NER_R11_OPS_DEPLOYMENT_CHECKLIST.md` 의 S4-1~S4-6 과 S2b 환경 표를 채운다(특히 S4-2 `required`).

4. 런북 절차대로 이미지를 비운영 환경에서 빌드·검증하고 이전 이미지 태그를 보존한다.
5. 사용자가 별도 최종 승인을 한다.
