# NER R12 사전 등록 (PERSON 노출률 5% 이하 도전, 마지막 고도화 실험)

버전 r12-prereg-1.0. 작성 시점: 학습·평가 **전**. 표시: 자동 검증 기반 연구용 · 사람 검수 미완료. 이 문서의 수치·규칙은 결과를 본 뒤 바꾸지 않는다(바꾸면 태그를 새로 달고 이유를 기록한다).

## 0. 범위와 보호
- 기존 R11 모델·ONNX·봉인 평가셋(`r11_stress_v1.jsonl` 2,350문장, `EVALUATED.lock`)·P1~P9 결과·`KEEP_S0` 판정·운영 적용 상태는 건드리지 않는다. R12 는 **별도 아티팩트**(`ner-runs/r12/…`)로만 만든다.
- 이번이 마지막 고도화 실험이다: 목표 미달이면 수치와 원인만 보고하고 **추가 재학습을 자동 진행하지 않는다.** 운영 배포·모델 교체는 하지 않는다.
- 평가 서비스 코드는 최신 `release/1.4`(PR #521 포함)의 `app/shared/privacy`다. 서비스 코드는 이 실험에서 바꾸지 않는다.

## 1. 가설
R11 의 PERSON 노출 129건(개발셋 8.62%) 중 완전 노출 96건의 대부분(89건)이 NER 미탐이고 69건이 D1P(일반명사 모양 이름)였다. 사전·후처리·규칙은 개선하지 못했다(최선 7.68%, Precision −7.5pp). 원인은 **문맥으로 사람/명사를 가르는 능력 부족**이라고 보고, 같은 낱말을 사람과 일반명사로 모두 쓰는 자연스러운 문장으로 재학습한다.

## 2. 학습 구성(하나로 고정)
- 모델: KoELECTRA-small(`monologg/koelectra-small-v3-discriminator`) 유지, 학습 조건은 R11 B군과 같다: max_len 128, batch 32, lr 5e-5, 최대 8에폭, patience 2, warmup 0.1, weight decay 0.01, 시드 **7·13·21·42·99**, `--klue-ratio 0`.
- 학습 데이터 = R11 B군 그대로(`baseline_train`, `synth_train`, `klue_train:469`, `r9_Ffull_train`, `r11_B_extra`) + **신규 `r12_extra`**(아래). R11 데이터를 빼지 않아 회귀를 막는다.
- 체크포인트 선택: `--select-on r12_val`(겹침 F1, 양성 대조쌍·음성 포함 새 검증셋). `baseline_val`·`synth_val` 은 모니터링. 에폭별 최고 겹침 F1 이 `best`. SWA·가중치 평균·B-new 유도는 하지 않는다(단일 구성).
- 시드 안정성: 5시드 전부 학습하고 평균·표준편차를 보고한다.

## 3. 신규 데이터(실제 문장을 직접 작성, 템플릿 치환 금지)
| 세트 | 문장 수 | 용도 | 구성 |
|---|---:|---|---|
| `r12_extra` | 2,800 | 학습 | D1P/D1 대조쌍 1,680(280단어 × 사람 3 + 명사 3), 성 없는 2·3자 이름+조사·호격 320, 별명·애칭 160, 인접·나열 다인물 240, 끝글자·경계 취약 200, 가족 채팅 자연문(이름 유/무 혼합) 200 |
| `r12_val` | 485 | 선택·조기 종료 | 쌍 240(60단어 × 4), 성 없는 이름 30·조사 호격 이름 30, 별명 15, 인접 이름 25, 다인물 25, 경계 B1 24·BND 16, 자연문 양성 40·음성 40 |
| `r12_dev` | 485 | 후보 게이트 | `r12_val` 과 같은 구성, 단어·이름·문장 모두 별개 |

- **중복 통제**: 세 세트의 `pair_word`·PERSON 값은 서로 겹치지 않게 미리 배정한 풀에서만 쓴다. 이름 풀은 R11 개발·검증·baseline 정답 이름과도 겹치지 않게 거른다. 문장 틀(앞 3어절+종결 패턴) 4-gram 중복, 같은 문장 중복, 세트 간 문장 겹침을 검사하고 초과분은 제거한다. **사람 문장의 30% 이상은 '이름표·별명·이름이' 같은 직접 단서 없이 행동·관계·조사로만 사람임이 드러나야 한다.**
- 합성 문장이며 사람 검수는 하지 않는다.
- **실제 수량(데이터 작성·겹침 정리 후, 학습 전 확정)**: `r12_extra` 2,742(이름 겹침 제거로 58행 제거, 쌍 단위), `r12_val` 485, `r12_dev` 476(9행 제거). 세트 간 문장·틀·대조 단어·PERSON 값 겹침 0, R11 개발·검증·baseline 정답 이름과도 0. 사람 문장 중 직접 단서 없는 비율: 학습 95.5%, 검증 99.2%, 개발 97.5%(기준 30% 이상). 작성은 서브에이전트(Sonnet)가 문장별로 직접 했고 규칙 검사기(`check_r12_marked.py`)를 전 배치가 오류 0으로 통과했다.


## 4. 개발 단계 게이트(독립 평가 **전**, R11 대비 같은 세트에서)
`r12_dev`, `r11_dev` 두 세트 모두에서 R12 시드 후보가 아래를 만족해야 '후보 적격'이다. 시드 확정은 적격 시드 중 **`r12_dev` 의 PERSON 전체 노출률이 가장 낮은 시드**(동률이면 F1 높은 시드)이며 독립 평가셋은 이 선택에 쓰지 않는다.
1. Exact Precision(공식) ≥ R11 − 2.0 %p
2. D1 일반명사 오탐률 ≤ R11 + 3.0 %p
3. 음성 문장 FPR(개발셋 NEG 4집합 매크로) ≤ R11 + 1.5 %p
4. PERSON 전체 노출률 < R11 (같은 세트)
5. KLUE val F1 ≥ R11 − 1.0 %p
6. ONNX 토큰 일치 ≥ 99.9%, p50 지연·크기·RSS ≤ R11 × 1.30

## 5. 독립 평가(새 평가셋, 한 번만)
- 평가셋: `r12_stress_v1.jsonl`(2,350, R11 스트레스와 같은 유형 코드·수량)과 `r12_representative_v1.jsonl`(800). 제작 지시서 `NER_R12_EVALSET_PRODUCER_INSTRUCTIONS.md`(별도 GPT 세션), 영역·비율은 지시서에 고정. 수령 후 변환·검증·겹침 측정·수량 맞춤·봉인한 뒤에만 연다. **후보(시드)가 확정되기 전에는 평가에 쓰지 않는다.**
- 비교: 같은 세트에서 S0·R11·R12(확정 시드). 평가 코드는 R11 최종 평가와 같은 방식(쌍 클러스터 paired bootstrap 5,000회, 95% 구간). **봉인 R11 평가셋 수치와 직접 비교하지 않는다**(다른 시험).
- 지표: Exact Precision/Recall/F1, PERSON 전체·완전·부분 노출률, D1P Recall, D1 일반명사 오탐률, 음성 FPR, 쌍 문맥 정확도, p50/p95 지연, 모델 크기, RSS.
- **채택 권고 조건(모두 충족, 같은 세트의 R11 대비)** — 스트레스 세트 기준 점추정:
  1. PERSON 전체 노출률 ≤ 5.0% (스트레스 세트), 대표 세트에서도 ≤ 5.0%
  2. Exact Precision ≥ R11 − 2.0 %p, Exact F1 ≥ R11 − 0.5 %p
  3. D1 일반명사 오탐률 ≤ R11 + 3.0 %p, 음성 FPR(A3N·D2·GENERIC·OTHER 매크로) ≤ R11 + 2.0 %p, 대표 세트 음성 문장 FPR ≤ R11 + 1.5 %p
  4. 지연·크기·RSS ≤ R11 × 1.30
- 결과 분류: **채택 권고**(1~4 충족) / **채택 보류**(노출률은 개선됐으나 2·3 중 하나 이상 위반) / **5% 미달**(1 미충족: 수치와 원인 보고, 추가 학습 자동 진행 없음) / **UNVERIFIED**(독립 평가 미완료). Exact Recall·F1 90%는 도전 목표이며 합격 조건이 아니다. 노출률이 개선되지 않으면 Recall 이 올라도 성공으로 판정하지 않는다.
- 기존 평가 기준·분모는 바꾸지 않는다. 독립 평가 결과로 임계값·모델을 다시 고르지 않는다(시드 선택은 개발 단계에서 끝난다). 확정 시드 외 4시드는 판정이 고정된 뒤 안정성 보고용으로만 평가한다.

## 6. 산출·보존
