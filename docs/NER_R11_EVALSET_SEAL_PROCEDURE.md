# R11 독립 평가셋 제작·검증·봉인·1회 평가 절차 (사양 `NER_R11_EVALSET_SPEC.md` r11-1.0, 2,350문장 안 확정)

2026-11-20 작성. **이 문서는 절차 준비다. 평가셋의 실제 생성·봉인은 사용자의 별도 승인 후에만 시작한다.** 최종 독립 평가는 사전 등록 r11-1.4 의 게이트·R11-S 를 통과한 적격 후보가 있을 때만 실행한다(없으면 실행하지 않고 S0 유지).

## 1. 확정된 구성 (사용자 승인 2026-11-20)

대표 1,600(사람 950 / 기타 250 / 없음 400) + 스트레스 2,350(사람 1,800 / 기타 50 / 없음 500) = 3,950문장.
스트레스 유형별: A1 150, A3 100, B1 240, B2 80, C1 100, C2 200, D3 100, **D1P 300 + D1 300(300쌍, `pair_id`·`role`·`pair_word`)**, D2 100, A3N 60, GENERIC 40, OTHER 50, **NEWNAME 310, LONGNAME 120, ORGLOC_MIX 100**. 수량 검증표: 사양 §15.

|---|---|---|---|

## 3. 봉인 매니페스트 필드

`version`(r11-1.0), `spec_commit`(사양 커밋 해시), `prereg_tag`(`r11-prereg-1.4`), `files`(파일명, 행 수, SHA256), `validator`(이름·버전·해시), `validation_summary`(오류 0, 경고 코드·건수), `overlap_summary`(건수·비율, 원문 없음), `review_summary`(검수 문장 수, 오류율, 합의), `type_counts`(유형별 문장 수), `pair_summary`(쌍 수, 서로 다른 단어 수, 단어당 최대 쌍 수), `sealed_at`(UTC), `sealed_by`, `approved_hash`(사용자 승인 해시), `read_only`(true), `notes`(NOTES.md 해시). 봉인 후 수정은 새 버전으로만 하며, **결과를 본 뒤의 수정은 해당 세트를 개발용으로 분류**한다.

## 4. 접근 규칙(후보 선정과 독립)

- 학습·후보 선정(B 학습, 게이트 판정, `select_r11.py`) 코드와 데이터 경로에 봉인 폴더가 없다. 봉인 폴더를 읽는 코드는 12 단계의 평가 스크립트 하나뿐이며 R11 후보 확정과 G12 통과 전에는 실행하지 않는다.
- 적격 후보가 없으면 평가셋을 열지 않는다(제작·봉인은 끝나 있어도 평가는 실행하지 않고 S0 를 유지한다).
- 봉인 이후 평가셋 문장·이름은 학습 세션도 열람하지 않는다(건수·id·지표만).
- 이 절차의 어떤 단계도 R12 이후의 모델 고도화를 계획하지 않는다.
