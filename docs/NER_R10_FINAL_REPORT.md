# R10 연구 최종 보고서 (정식 마감, 후보 없음)

작성: 2026-11-20 · 대상: 소통 에이전트 가족 대화 PERSON 가명화 KoELECTRA NER (R10 라운드)
상태: **R10-full 5시드 중 G1~G11 전체를 통과한 후보가 없다. 독립 최종 평가와 운영 모델 교체는 진행하지 않는다.**
관련 문서: `NER_R10_PREREGISTRATION.md`(§11 보완 포함), `NER_R10_EVALSET_SPEC.md`, `NER_R10_MODEL_SEPARATION_DESIGN.md`, `NER_R10_ERROR_ANALYSIS_AND_R11_PROPOSAL.md`(원인 분석·R11 제안)

## 0. 요약

- 사전 등록된 30회 학습(6개 군 × 5시드)과 개발 평가를 전부 정상 완료했다. 학습 조건·데이터·평가 기준·게이트는 사전 등록 값 그대로이며 **사후에 바꾸지 않았다**.
- R10-full 5시드는 각각 다른 게이트에서 탈락했다(§3). 적격 시드 0개이므로 G11(≥3시드 적격 + 5시드 평균 비악화)도 실패다.
- 신규 데이터 효과: 사전 등록 비교(C10 대비 R10-full)로는 대상 4개 매크로 노출 −4.39pp(기준 −1.0pp 충족)이지만, R9F 대비로는 −2.0pp이고 시드 편차가 크다(R10-full sd 4.0pp). 이 결과를 "개선이 확인됐다"로 읽으면 안 된다(§4).
- 운영 ONNX 모델, 공용 코드, 다른 에이전트는 바꾸지 않았다. R9 봉인 평가셋·R10 독립 평가셋은 열지 않았다.

## 4. 신규 데이터 효과와 귀속 (인과 주장의 한계)

| 비교 | 대상 4개 매크로 노출(평균) | 차이 |
|---|---|---|
| C10 → R10-full | 20.1 → 15.8 | **−4.39pp** (사전 등록 기준 ≤ −1.0pp 충족) |
| R9F → R10-full | 17.8 → 15.8 | −2.0pp |
| R9F → C10 | 17.8 → 20.1 | +2.3pp |

- C10 은 R9F 에 학습 행 2,100개(R9F 행의 재추출)를 더해 스텝 수를 맞춘 통제군이다. C10 이 R9F 보다 나빠졌으므로(+2.3pp), "C10 대비 −4.39pp"의 상당 부분은 **C10 이 나빠진 데서** 왔다. R9F 기준으로는 −2.0pp 이고 R10-full 의 표준편차(4.0pp)보다 작다.
- 귀속 군(R10-D 20.4, R10-BC 19.7, R10-N 21.6, C10s 20.7; 표준편차 약 3pp)은 서로, 그리고 C10s 와 구분되지 않는다. 사전 등록 기준에서 새 데이터의 어느 구성요소가 효과를 냈는지는 **주장할 수 없다**.
- 5시드로는 R10-full 시드 간 변동(D1P 34.9~59.7%)이 평균 차이보다 크다. 사전 등록 규칙(≤ −1.0pp)은 충족하지만 "신규 데이터가 D1P 를 줄였다"고 단정하면 안 된다.
- KLUE: 같은 KLUE 469행·같은 총 학습 행 수인데 R10-full 의 KLUE PERSON F1 이 C10 보다 −3.08pp 낮아 사전 등록 경고 기준(−2.0pp)을 넘었다(비PERSON 오탐은 −0.45pp 로 경고 아님). KLUE 비중 차이(R9F 6.0% vs R10 4.73%)로는 C10 과의 차이를 설명할 수 없다(두 군 동일). 원인 분석은 별도 문서 §D.

## 5. 한계와 `baseline_val` 포화

- **`baseline_val` 포화**: 30개 런의 최고 val F1 은 0.968~1.000 의 7개 값뿐이고, 80% 의 런에서 둘 이상의 에폭이 최고값과 동률이다. 값 하나가 엔티티 한 개 수준(약 0.6pp)이라 모델 간 차별력이 거의 없다. 최고 val 과 개발 지표의 순위상관도 약하다(D1P ρ=0.04, 대상 4개 ρ=−0.11, R9dev ρ=−0.18, 30개 런 기준). 사전 등록된 에폭 선택 기준은 **사후 변경하지 않았고**, 한계로만 기록한다. R11 에서 새 사전 등록으로 다룬다.
- 개발 셋 크기: D1P/D1 쌍 149개, C2 120문장, B1 150문장 등으로 작아 시드 간 차이와 구분하기 어렵다. 개발 셋은 이번 분석으로 "열람된" 상태이므로 R11 선정에는 새 개발 셋이 필요하다.
- 시드 5개의 불확실성: 군 간 평균 차이의 대부분이 시드 편차 범위 안이다.
- R9F 는 R9 에서 학습한 모델을 재사용했다(사전 등록). 같은 조건이지만 R10 세션에서 다시 학습한 값은 아니다.
- 라이선스: KLUE-NER CC BY-SA 4.0(서비스 사용 전 법무 검토 필요), Nemotron-Personas-Korea 파생 개발 셋 CC BY 4.0(평가용), `koelectra-small-v3-discriminator` 라이선스 미표기(2026-11-20 확인). 변경 없음.
