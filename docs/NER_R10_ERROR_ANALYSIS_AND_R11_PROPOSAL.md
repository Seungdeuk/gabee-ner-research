## 1. 핵심 결론 (6줄)

1. D1P 미탐과 D1 오탐의 트레이드오프는 **문맥을 읽는 능력보다 "단어가 사람 이름처럼 보이는가"라는 단어 단위 편향**이 지배한다. 같은 단어의 사람 문장과 명사 문장에 같은 판정을 내리는 쌍이 대다수이고(모델별 72~86%), 문맥으로 정확히 구분한 쌍은 9~23% 뿐이다.
2. R10 데이터는 문맥 구분 쌍을 **R9F·C10 보다 늘렸다**(5시드 모두 26~35개/149, R9F 14~27, C10 13~33). 그러나 모델이 선택하는 **운영점(이름 쪽/명사 쪽)이 시드마다 달라** 이 이득이 D1P·D1 개별 게이트에서는 사라졌다.
3. 시드 변동의 직접 징후: R10-full 은 이름 확률이 경계 구간(0.1~0.9)에 있는 비율이 46~47%로 R9F·C10(12~24%)의 약 2배이고, 시드 간 판정이 갈리는 단어가 40%(R9F 25%, C10 30%)다.
4. R9dev 노출 악화(4.2→5.4%)의 상당 부분은 **데이터 내용이 아니라 학습량 증가 자체**와 **특정 시드의 신뢰도 하락**에서 온다. C10(신규 데이터 없음)이 이미 5.0%이고, 악화는 특정 시드·세트(시드 7 `v14_realistic`, C10 시드 13 같은 세트)에 몰려 있으며 대부분 2글자 이름이다.
5. `baseline_val` 은 포화되어(7개 값, 80% 런에서 최고값 동률) 운영점과 무관한 체크포인트를 고른다. 최고 val 과 D1P·R9dev 의 순위상관은 ±0.2 이내다.
6. KLUE 하락(C10→R10-full F1 −3.1pp)은 KLUE 비중이 아니라 **R10 추가분의 분포**(5자 이상 이름 0%, ORG/LOC 문장 2.7%, 짧은 문장)와 조사 없는 이름·명사 대조 문장 학습 방향의 영향이 의심된다(가설).

### A-5. 가능한 원인 후보 (관찰 / 가설 구분)

- (관찰) 단어 단위 편향이 지배적이고 시드가 운영점을 정한다.
- (관찰) R10 은 문맥 구분을 늘렸으나 확률이 경계에 몰려 시드에 취약하다.
- (가설 H1) 대조 쌍의 단어 다양성(학습 어휘 121개)이 작아 모델이 "문맥"보다 "단어 사전"을 외운다 → 단어·프레임 조합을 늘리면 줄어든다.
- (가설 H2) 쌍 단위 학습 신호(같은 배치 안 대조)가 없어 두 문장의 결정이 독립적이다 → 쌍을 같은 배치에 묶고 일관성/마진 손실을 두면 개선된다.

### B-2. 시드 7 `v14_realistic` 악화 원인

- 시드 7 은 `v14_realistic` 정답 97개 중 **19개 노출(19.6%)**, R9F 는 0~2개. 동일 현상이 **C10 시드 13 에서 16개(16.5%)** 로도 나타났다 → 신규 데이터 내용만의 효과가 아니라 **특정 시드에서 이 세트의 이름 표현에 대한 신뢰도가 무너지는 현상**이다.
- 단계: 시드 7 의 R9F 대비 새 노출 134건 중 **88건(66%)이 "원시 PERSON span 은 있으나 점수<0.5 라 `merge_ner` 가 버림"**, 23건 경계 구간 미탐(P 0.1~0.5), 10건 경계 오류. C10 시드 13 도 33건 중 19건이 점수 탈락. 길이는 시드 7 에서 2글자 이름이 134건 중 109건(81%).
- 가설 H3: 2글자 일반명사를 이름 아님으로 가르치는 대조 문장이 **2글자 이름의 신뢰도를 낮춘다**. 이 가설은 이 데이터로 검증할 수 없다(새 실험 필요).
- 점수 임계값 민감도(탐색용, 사전 등록 무관; `merge_ner` 최소 점수만 낮춘 근사): 임계값 0.5→0.35 에서 R10-full 의 R9dev 합산 노출 5.15→4.70%, D1P 45.2→43.5%, D1 오탐 34.9→36.9%(+2.0pp). R9F 는 4.31→4.09%, C10 4.35→4.18%. **격차는 일부(0.84→0.61pp)만 줄어** 점수 탈락이 회귀의 전부는 아니다. 공용 모듈(`ner.py`) 변경이므로 별도 승인 없이는 검토하지 않는다.

| R10-full | 45.2 ± 10.5 | 34.9 ~ 59.7 |

- R9F 는 가장 안정적(sd 2.0)이나 D1P 개선이 없다. R10-full 은 평균이 가장 낮지만 sd 가 5배다. 학습량·데이터가 늘수록 시드 분산이 커졌다(R9F → C10 → R10-full).

### C-2. `baseline_val` 포화가 체크포인트 선정에 미친 영향

- 30개 런의 최고 val F1 은 0.968, 0.974, 0.981, 0.987, 0.993(2종), 1.000 의 7개 값뿐이다(값 간격이 약 0.6pp 라 엔티티 1개 수준으로 추정, 검증 엔티티 약 160개). **80% 의 런**에서 둘 이상의 에폭이 최고값과 동률(선택은 동률 중 하나).
- 최고 val 과 개발 지표의 순위상관(30개 런): D1P 0.04, 대상 4개 매크로 −0.11, R9dev 노출 −0.18 → **선정 신호로 쓸 수 없다**. 군 내 5시드 상관은 R10-full 0.11·0.00, C10 0.72·0.46 로 일관되지 않고 n=5 라 우연 범위다.
- 사전 등록된 에폭 선택 기준은 이번 라운드에서 바꾸지 않았다. R11 에서 새 사전 등록으로 개선한다(§6).

### C-3. R9F 와 R10-full 의 시드 편차 비교

R10-full sd: D1P 10.5, 신규 이름 3.9, R9dev 2.8, 대상 4개 4.0. R9F sd: 2.0, 0.9, 0.5, 1.0. B1 은 5시드 모두 R9F 평균(8.6%)보다 낮다. D1P·D1·R9dev 는 시드 간 방향이 갈린다(예: D1P 는 3시드가 R9F 평균보다 낮고 2시드는 높다).

### D-3. 해석

- (관찰) R10 신규분은 5자 이상 이름·ORG/LOC 문장이 사실상 없고 문장이 짧으며 이름 닮은 명사 대조 문장(19%)이 새로 들어갔다. 같은 2,100행을 C10 은 R9F 행으로 채웠다(ORG/LOC 31.6%).
- (관찰) KLUE 하락은 긴 이름(5자 이상, 외래어 이름·직함 포함 가능)과 조사 뒤 이름의 미탐 증가로 나타난다. 이름 닮은 명사 학습의 영향(가설 H4: "낯선 단어는 명사") 또는 엔티티 라벨 다양성 감소(가설 H5)로 설명 가능하며, 둘 다 새 실험으로만 확인할 수 있다.
- 라벨 정책 차이: r9-1.1 별칭 정책과 1글자 이름 제외 정책이 KLUE 정답(1글자 585개 모두 미탐)과 충돌한다. 이 585개는 모든 모델에서 동일하게 미탐이므로 C10↔R10-full 차이와 무관하다.

## 6. R11 설계 제안

### 6-1. 원칙

- 신규 모델이 "왜 더 안전하고 안정적이어야 하는지"를 학습 전에 사전 등록한다. 평균이 아니라 **시드 안정성과 쌍 단위 문맥 구분**을 1차 목표로 둔다.
- R9F 의 전체 보호 성능(R9dev 노출 4.2%, F1 91.5%)을 **유지 조건**으로 둔다. R10 에서 학습량 증가 자체가 회귀를 만들었으므로 **스텝 수를 R9F 와 맞춘 대조군**을 필수로 둔다.

### 6-2. 개발 데이터에서 이미 분석 가능했던 것 / 새 실험으로만 검증 가능한 가설

| 구분 | 내용 | 근거·상태 |
|---|---|---|
| 분석으로 확인(완료) | 트레이드오프는 단어 단위 운영점 이동, R10 의 문맥 구분 소폭 개선, 시드 불안정과 확률 경계 집중, 회귀의 일부는 학습량 효과(C10), 점수 탈락·경계 오류의 단계 분해, `baseline_val` 포화, KLUE 오류 분포 | 본 문서 §2~5 |
| 새 실험 필요 | H1 어휘·프레임 다양성, H2 쌍 단위 일관성 학습, H3 2글자 이름 신뢰도 하락, H4 낯선 단어=명사 학습, H5 ORG/LOC·긴 이름 다양성, 가중치 평균·EMA 의 분산 감소, 보정(온도 조정)의 효과 | 아래 실험 |

### 6-3. 우선 검증할 가설 3개

1. **분산·운영점 안정화(학습 절차)**: R10-full 과 같은 데이터에서 "마지막 k 에폭 가중치 평균 또는 EMA", "쌍 일관성 손실(같은 단어의 사람 문장 P(이름) > 명사 문장 P(이름) + 마진)" 이 시드 분산을 줄이고 문맥 구분 쌍을 늘리는가? 데이터 추가 없이 학습 절차만 바꾸므로 가장 싸다.
2. **대조 데이터의 어휘·프레임 다양성(데이터)**: 대조 단어를 121개에서 300개 이상으로, 단어당 프레임 수를 늘리면 단어 사전 암기 대신 문맥을 쓰는가? 2글자 일반명사만 음성으로 쓰는 편향이 2글자 이름 신뢰도를 해치지 않는지를 같이 보기 위해 **2글자 이름의 정상 문맥 문장을 같은 수만큼 동반**한다.
3. **스텝 수 대조(회귀 귀속)**: R9F 와 총 스텝 수를 맞춘 R10 데이터 군(행을 줄여 같은 스텝)이 R9dev 노출 4.2% 를 유지하는가? C10 이 포착한 학습량 효과와 데이터 효과를 분리한다.

### 6-4. 최소 비용 실험 설계 (총 15런 ≈ 1~1.5시간, 런당 약 4분)

| 군 | 내용 | 데이터 | 시드 |
|---|---|---|---|
| R11-A | R10-full 데이터 + 가중치 평균(마지막 3에폭) | R10 신규분 그대로 | 5 |
| R11-B | R10-full 데이터 + 쌍 일관성 손실(마진) | R10 신규분 그대로 | 5 |
| R11-C | 스텝 수를 R9F 와 맞춘 R10 군 + 대조 단어 확장분 일부 | 신규 대조 데이터 일부(생성은 별도 승인 후) | 5 |
| 재사용 | R9F, C10, R10-full, S0 | 기존 결과(재학습 없음) | 5 |

A·B 는 데이터 생성이 필요 없다. A·B 로 분산 가설(H1·H2)을 먼저 검증하고, 효과가 있을 때만 C(새 데이터)를 만든다 → **데이터 제작을 미루고 학습 절차 실험부터** 한다.
KLUE 보호를 위해 모든 군의 학습 데이터에 5자 이상 이름·ORG/LOC 문장을 R9F 수준(문장의 약 30%)으로 유지하는 조건은 새 데이터(C)에서 명시한다.

### 6-5. 검증 지표와 체크포인트 선정 기준(새 사전 등록)

- **쌍 단위 문맥 정확률**(사람 가림 + 명사 정상 쌍 비율)과 **노출률**(우선), D1P 노출·D1 오탐은 보조.
- 체크포인트 선정은 `baseline_val` F1 단독이 아니라, 별도 **검증 쌍 셋**(학습·개발·평가 어휘와 겹치지 않는 대조 쌍 약 300개, 합성)에서의 문맥 정확률과 노출률로 한다. `baseline_val` 은 동률 타이브레이커로만 쓴다.
- 시드 안정성: 5시드 중 ≥4 시드가 개별 게이트 통과, 개별 시드 최악값 보고. 게이트 G1 은 문장 1개가 5pp 인 세트의 거친 해상도를 고려해 **건수 기준**(예: 서비스 대비 +1문장 이내 + 신뢰구간 병기)으로 재정의한다(새 사전 등록).
- R10 의 G1~G11 은 R10 평가에만 적용하며 사후 변경하지 않는다.

### 6-6. 새로운 사전 등록·독립 평가 계획

- 학습 전 사전 등록: 군, 시드(7, 13, 21, 42, 99), 학습 조건, 선정 규칙, 게이트, 통계 방법(쌍 단위 부트스트랩), 실패 시 처리를 먼저 고정하고 개발 평가 전에 커밋한다.
- 새 개발 셋(R10 dev 와 어휘·템플릿 분리)과 새 검증 쌍 셋을 만든다. R10 dev 는 이번 진단으로 열람됐으므로 선정에 쓰지 않는다.
- 독립 최종 평가: 기존 `NER_R10_EVALSET_SPEC.md`(대표 1,600 + 스트레스 2,000, 별도 세션 생성·봉인, 540문장 이중 검토)를 유지하되 쌍 단위 사분면 지표와 5자 이상 이름·ORG/LOC 혼합 문장을 추가한다. 최종 후보 확정 후 1회만 평가한다.
- 운영 모델 교체와 소통 전용 분리 구현은 R11 후보가 사전 등록 기준을 통과하고 별도 승인을 받은 뒤에만 진행한다.

## 7. 남아 있는 위험과 확인되지 않은 사항

- 개발 셋이 작다(D1P/D1 쌍 149개, 단어 어휘 한정). 시드 5개로는 군 평균 차이의 대부분이 시드 편차 안이다. "문맥 구분 소폭 개선"도 통계적으로 확정하지 못했다.
- 점수 탈락·경계 오류의 단계 분해와 임계값 민감도는 `merge_ner` 의 규칙 병합 세부를 재현하지 않은 근사다. 공용 `ner.py` 임계값 변경은 별도 승인 사항이다.
- H1~H5 는 모두 가설이다. 특히 H3(2글자 이름 신뢰도), H4(낯선 단어=명사)는 새 실험 없이는 구분할 수 없다.
- R9F 는 R9 에서 학습한 모델이라 R10 세션 재학습 값이 아니다(같은 조건이나 직접 재현은 아님).
- KLUE 5자 이상 이름의 정체(외래어 이름, 직함 포함 여부)는 본문을 열람하지 않아 분류하지 않았다.
- 학습량 증가가 회귀를 만든다는 해석은 C10 한 군(5시드)에 근거한다. 다른 학습량에서의 재현은 확인하지 않았다.
